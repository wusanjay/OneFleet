深度调研 · 一人公司执行方案

多 Agent 协同：这一波风口，独立开发者还能不能上车？ 从 DeepSeek Bot 与 OpenClaw 两波浪潮的完整复盘，到一份可执行的 24 周作战计划

调研时间：2026 年 10 月 12 日　·　起点材料：Datawhale《DeepSeek Bot 发布！装个插件就能用！》（2026-10-11）
面向对象：全栈独立开发者 / OPC 一人公司 / 个人 IP 创业者
EXECUTIVE SUMMARY

先给结论

在展开论证之前，把最关键的六条判断放在前面。

修正一个关键假设：国内大厂不是"很快跟进"，是"已经在场"

你判断"目前都是国外大厂在做，很快会刮到国内"——这条需要修正。截至 2026 年 10 月，国内大厂的多 Agent / 智能体产品已经全面铺开并进入淘汰赛：字节"豆包工作"（与飞书深度打通）、阿里"千问办公"（整合 QoderWork / MuleRun / 悟空，对接钉钉）、腾讯 WorkBuddy（把 QClaw 团队整合进去，6 月单月访问量 2097 万次）、网易 LobsterAI（2 月发布，国内大厂首个开源桌面 Agent，用户已破 100 万）、百度"搭子"（月活 674 万）、联想天禧 AI 4.0、华为小艺多智能体。

这意味着：这一波留给个体的"信息差窗口"比 OpenClaw 那波更短，但"能力差窗口"更长。你的机会不在"做个更好的工具"，而在"做一套别人抄不走的编排方案 + 信任资产"。

8–10 周 OpenClaw 那波的纯信息差窗口（2026 年 1 月爆火 → 3 月见顶 → 5 月腰斩）
30–45 万 淘宝单一店铺靠 OpenClaw 安装服务，近一个月售出 3000+ 单的收入
0 元 这一波"代安装"生意的天花板——官方插件一键装，门槛生意直接归零

六条核心判断

  1. 方向判断正确，但形态要升级。"单 Agent → 多 Agent 团队"确实是主升浪：DS Bot 一天 250+ star、DSH 官方自己上线"智能体团队"预览、OpenClaw 2.0 主打 multiplayer、OpenClaw Enterprise 定位"agents 的 Kubernetes"、蚂蚁灵光 2.0 对标 Meta Muse。叙事成立。
  2. "本地优先"不再是壁垒。网易 LobsterAI 已经把"不锁定、不强制登录、数据全本地、接入所有 IM"做成了产品卖点并开源，而且拿到了 100 万用户。把它当唯一差异化，会被正面撞车。
  3. 卖铲人的第一层（代装、教程）这一波基本没有了。门槛是那波生意的唯一养料；官方一键安装把门槛抹平了。这波的钱在"编排"这一层。
  4. 真正稀缺的是"行业编队知识"，不是代码。同一批 Agent，用什么角色拆、什么顺序跑、卡在哪儿验收——这是大厂做不了的长尾，也是你唯一守得住的东西。
  5. 变现应按"内容 → 模板 → 陪跑"三层叠加，而不是二选一。历史数据反复证明：一次性服务（代装）在退潮时归零，内容与信任资产可以迁移到下一波。
  6. 合规不是阻碍，而是护城河。2026 年 5 月《智能体规范应用与创新发展实施意见》已把智能体纳入监管；做"本地工具 + 人工交付"而非"面向公众的 AI 服务"，合规成本极低，反而是大厂做长尾服务时的束缚。
PART 01

风口判读：这篇文章到底在说什么

先把起点材料拆干净，再判断它代表的是不是一个真实的趋势转折。

1.1 起点材料：DeepSeek Bot（DS Bot）

Datawhale 在 2026 年 10 月 11 日转发的，是开发者 FeiZhuLulu（FeiZ） 在 GitHub 开源的一个插件：deepseek-bot。它本身不是 DeepSeek 官方产品，而是长在 DeepSeek Harness（DSH） 这个开源智能体运行时上的一颗插件。DSH 的设计哲学是"一切皆插件"，所以装上它，DSH 就从"一个对话窗口"变成"一支 Bot 团队"。

机制具体设计背后的产品意图
Chief 主 Bot首次启动自动创建高权限主管 Bot，负责创建/配置其他 Bot 与群聊；作者建议"别读配置文档，直接跟 Chief 说话"用对话替代配置界面，把多 Agent 的上手门槛压到接近零
群聊 + 管理员 Bot每个群有管理员 Bot，默认由它回复用户，按需再调用其他 Bot；也可直接 @ 某个成员直接解决多 Bot 同时回复导致的 Token 爆炸问题
长期记忆每个 Bot 一套 Markdown 记忆文件，团队另有一份共享记忆；每轮对话后模型自动审查该记、该改、该删什么把"重复交代"变成一次性设置
独立上下文每个 Bot 对应一个 DSH session；超长时用压缩、交接摘要、本地全文检索（SQLite）应对解决多 Agent 场景下的上下文管理
按 Bot 选模型写手 Bot 和程序员 Bot 可以用不同模型；设置页按时间/Bot/模型统计 Token 用量成本可见、按角色配算力
全本地存储数据落在 ~/.dsh 下的 bot/ 与 sessions/，卸载插件不删除数据隐私与数据主权

许可：Apache 2.0　·　版本：v0.1 预览版，基于 DSH 0.2.1-alpha.1　·　星标：发布 1 天 250+，10 月 11 日已过 450

读这篇文章的正确姿势

别被"DeepSeek 官方发布"的标题带跑——这是社区插件的开源事件。真正值得读的信号有三层：① DSH 官方同期已上线「智能体团队」预览功能（主 Agent 当队长、队友间直接通信、共享任务板、消息幂等），说明多 Agent 是官方认定的下一站；② 社区在官方开放插件体系后 48 小时内就长出爆款，说明生态位是真实存在的且有强需求；③ 作者自己承认参考了 AgentMemoryRepo、OpenMausBot、OpenCode、goose、pi、Gemini CLI、obelisk 等一批项目的设计——说明这个领域目前是"重组式创新"，不是"从零原创"，对独立开发者极其友好。

PART 02

复盘：OpenClaw 风口期，国内到底是谁赚到了钱

这是本次调研最有价值的部分。把上一波赚钱的人按层级拆开，你的可复制性一目了然。

2.1 五层赚钱图谱

L1
硬件层 · 卖"跑 Agent 的机器"
因为 OpenClaw 需要 7×24 常驻、且强调数据本地化，很多人选择单独买一台机器跑它，Mac mini 成了事实标准。
· 二手苹果经销商：7 天卖出 200 台 Mac mini M4，相当于平时一个月的销量，按 4000 元计约 80 万营收（不含高配机型）
· 深圳二手电脑商李工：推出"预装 OpenClaw 的 Mac mini / MacBook"，两周内订单增长 8 倍
可复制性：中（需要硬件供应链，但"预装 + 教学"是纯增量）
L2
交付层 · 卖"帮你装起来"（最快现金流）
OpenClaw 要开终端、配 API、接消息渠道，绝大多数人搞不定，于是诞生了一个短暂而暴利的服务市场。
· 价格带：远程安装 50–100 元 / 次；上门安装 300–1000 元，500 元最常见
· 淘宝某店：近一个月售出 3000+ 单安装服务，创收 30–45 万元
· 上海 AI 产品经理李岸：基础上门 500 元，企业定制几千到上万；周末两天装十几单
· 高客单案例：一位外贸老板在闲鱼花 8000 元定制"竞品监控小龙虾"，24 小时抓取海外平台产品信息并分析
· 海外对标：SetupClaw 把代部署做成标准化产品——远程 5000 美元、托管 3000 美元、湾区上门 6000 美元起，创始人称年收入有机会做到 100 万美元量级
· 反向收割：退潮后出现 299 元"上门彻底卸载 + 清理注册表"服务
可复制性：高，但生命周期极短——门槛一消失，生意立刻归零
L3
知识层 · 卖"教你怎么装、怎么用"
· 杭州自媒体博主阿凯：花 3 天整理 99 元零基础部署教程（含视频），上线一周只卖十几份，热度过峰后 2 周卖出 800 多份 ≈ 8 万多元；顺势做 100 元付费交流群，200+ 人

L4
产品层 · 卖"Skill / 插件 / 垂直 SaaS"（复利）
· Skill 开发：最小只要一个 SKILL.md 文件，放进去重启即可用；发布到 ClawHub 按使用量分成
· 垂直 SaaS 包装：把 Agent 能力封成网页工具，月订阅 29–99 美元
· 被公开报道的案例：一位大三学生从 2025 年 9 月开始做 OpenClaw 技能包——电商数据抓取 99 元/月、学员管理 99 元/月、内容批量生成 199 元/月，300 个订阅用户 + 3 个定制项目 + 20 名培训学员 ≈ 月入 10 万元（来源为媒体报道，建议只当量级参考）
· 分销 API：有服务商称两周赚 5 万

· 猎豹移动 CEO 傅盛：滑雪摔伤卧床期间开始直播"养龙虾"，14 天把 8 个 Agent 养成了一个 7×24 自动工作、还能自我迭代的团队，全程直播——用个人 IP 把技术热点转成了内容资产
· 北京"七师傅"（Chris Zhao）：组织 OpenClaw 社群与线下活动，入群要验"龙虾跑起来"的截图，靠社群运作积累影响力
· 政务场景：深圳福田区两个岗位正式上线"政务龙虾"（民生诉求分析员、卫生许可辅导员），审批效率提升 2–3 倍，一度冲上微博热搜
可复制性：极高，且资产可跨风口迁移——这是本次调研最推荐的战场

2.2 五条规律：钱到底是怎么赚到的

规律一：钱不在模型层，在"门槛差"上

OpenClaw 本身免费、开源、赚不到钱。所有赚到钱的人都站在"用户与工具之间的那道坎"上。门槛存在 → 服务有溢价；门槛消失 → 生意归零。所以判断一个风口能不能做，第一个问题永远是："门槛在哪，它多久会消失？"

规律二：一次性服务在退潮时归零，内容与产品会留下

代装是一锤子买卖，卸载服务也救不回来。但阿凯的教程、小鑫的账号、傅盛的直播、以及那些订阅制技能包，退潮后仍然有价值——因为它们沉淀的是"这个人是懂行的"这个认知。下一波来时，这批人不需要从零获客。

规律三：窗口只有 8–10 周，但"认知窗口"长得多

1 月爆火 → 3 月见顶 → 5 月腰斩，纯热度红利不到两个半月。但"谁是这一波里讲得最清楚的人"这个认知，会持续到下一波。所以节奏应该是：热度期抢内容，退潮期做产品，而不是反过来。

规律四：真正杀死上一波的，不是产品缺陷，是"补贴结束"

亲历者复盘认为，2026 上半年 AI Agent 的繁荣，很大一部分是模型厂商免费额度在买单；Anthropic 切断第三方订阅后，成本结构一夜改变，同类工具同涨同跌——说明驱动它们的根本变量在外部，与各自软件质量无关。这对你的启发是：你的商业模式必须不依赖任何一家的补贴活着。这正是"本地跑、用户自己带模型额度"的价值所在。

规律五：卖铲人内部也分层，越往上留存越久

L1 硬件 < L2 交付 < L3 知识 < L4 产品 < L5 内容 IP，赚钱速度和生命周期呈反向。L2 来钱最快也最先死；L5 最慢但能穿越周期。正确做法不是选一层，而是用 L2 的现金流养 L3/L5 的资产。

PART 03

两波对比：为什么这次"代装"没了，钱在哪一层

同一个叙事，第二波的结构已经完全不同。用错上一波的地图，会直接踩空。

维度OpenClaw 波（2026 Q1）多 Agent 波（2026 Q4）含义
上手门槛 高开终端、配环境、绑 API、接 IM 低插件市场搜一下、点安装 L2 交付层归零
载体归属 用户自建（本地或云主机） 官方 Harness / 官方桌面端内置 你无法再靠"提供载体"赚钱
大厂状态 3 月才被动跟进（做云部署） 已在场且打到淘汰赛 信息差窗口更短
谁在卖"装" 个体服务商，300–1000 元/单 被官方免费功能吃掉 不要再投这块
真正稀缺 会装（技术执行） 会编排（选哪些角色、什么顺序、如何验收） 这就是你的主战场
用户心智 "这玩意儿牛，我得试试" "我该让这 100 个员工替我干什么活" 从功能好奇转向场景需求
一个必须接受的反直觉结论

你想做的"本地优先的多 Agent 产品 demo"，作为流量入口和信任凭证非常有价值；但作为收入来源几乎没有价值。原因很简单：网易 LobsterAI 已经开源且免费、100 万用户；DSH、OpenClaw 生态里的开源多 Agent 编排项目已有几十个（Agent Teams 2.2k star、OpenDot、MyCoWork……）。在"工具"这一层，开源免费是默认价格。

所以正确定位是：Demo 是钩子，不是商品。

3.1 这一波真正的四个空位

空位一 · 行业编队 Know-how
大厂做通用办公，绝无可能去做"跨境电商选品三人组""独立律师助理团队""小红书爆款矩阵"这种长尾编队。你手里如果有一批真实跑通的编队方案，就是别人抄不走的东西。
空位二 · 中文场景内容
OpenDot、Agent Teams、MyCoWork 这些项目的文档和社区以英文为主；国内大厂产品的官方内容偏"功能介绍"。真正缺失的是"用大白话讲清楚一个具体岗位怎么被 Agent 编队替代"的中文内容。
空位三 · 本地 + 自带模型的成本结构
规律四说明：依赖补贴的模式会集体死亡。你的模式是"工具免费 + 用户自己带模型额度"，边际成本接近零，还能在成本敏感的中小商家与个人开发者里建立优势。
空位四 · 大厂不愿意做的"人肉交付"
企业侧的真实需求往往是"帮我把这个流程跑通并教会我的人"，客单价几千到上万，大厂不会接这种非标长尾。这是你稳定现金流最好的一层。
PART 04

你的定位：从"AI 工具商"转向"AI 编队方案商"

你原来的设想有 70% 是对的，需要修正三个地方。

4.1 原设想的逐条评估

你的想法评估调整建议
做一个类似产品 demo，可用作功能展示 保留 但目标不是"产品竞争力"，而是"3 分钟视频能让人看懂并转发"。功能广度让位给演示冲击力。
基于已有开源产品完善优化、组装修出手搓版本 保留 合法性上开源许可要看好（DS Bot 是 Apache 2.0，Agent Teams 是 AGPL-3.0，AGPL 有传染性，商用需谨慎）。建议：优先在 Apache/MIT 生态上做，或做"编排层 + 技能包"而非 fork 分发。
本地运行而非云端 → 成本低、差异化卖点 部分修正 成本低是真的；"差异化"已经不成立（LobsterAI 已开源、100 万用户）。把"本地"从卖点降级为特性，卖点换成"开箱即用的行业编队"。
录使用视频：跨行业工作流 / 一人公司 100 个 Agent 强烈保留 这是全案最重要的一步。傅盛用同一招把技术热点变成了个人 IP。"一个人开公司，有 100 个员工（Agent），还能拉群协作"这句话本身就是一个可传播的钩子。
以后国内大厂做起来会找我付费合作推广 可行但靠后 合作的前提是你有"某个垂直人群的信任度"。先把一个垂类的 1000 个精准付费用户做出来，大厂 BD 会主动找上来。顺序不能颠倒。
直播 / 小红书运营 保留 平台分工：小红书做"精准垂类 + 强付费意愿"，视频号/B站做"深度长内容 + 信任沉淀"，抖音只做泛流量曝光。参考张磊案例：1000 个精准付费粉 > 100 万泛娱乐粉。

4.2 一句话定位

我不卖 AI 工具，我卖"一支能替你上班的 AI 编队"。
工具开源免费（做流量和信任），编队方案收费（做利润），落地陪跑做高客单（做现金流），内容做护城河（做长期资产）。

PART 05

执行方案：24 周作战计划

核心节奏原则：热度期抢内容，退潮期做产品。不要等 demo 完美了再开始发声。

阶段 0 · 定位与资产盘点
第 1–2 周
  • 选一个垂类（这是全案最重要的一次决策）。筛选标准：① 该人群反复做重复性工作；② 他们已经在用 AI 但不满意；③ 有明确付费习惯。候选方向：跨境电商小卖家、独立律师/会计、小红书 MCN 矩阵、外贸 SOHO、SaaS 独立开发者、本地生活商家。
  • 盘点你的存量优势：你做过哪些行业？有哪些现成人脉？过去解决过什么具体问题？——你的第一支编队必须长在你已有的认知上，否则内容会空。
  • 选定技术底座并确认许可：优先 DSH（一切皆插件、生态新、机会多）或 MIT/Apache 类编排框架；避开 AGPL 传染风险。
  • 把个人 IP 的地基搭起来：统一的昵称/头像/一句话简介（含"AI 编队"关键词）；小红书 + 视频号 + GitHub 三处同名。
  • 建立选题库：先攒 30 条"我要说的观点"，不写内容，只列观点。
垂类确定底座选型完成三平台同名30 条选题
阶段 1 · MVP Demo（本地优先多 Agent）
第 3–6 周

原则：4 周必须出可录屏的版本，宁可 60 分能跑，不要 95 分没影。

  • 技术骨架：桌面壳（Electron/Tauri）+ 本地后端 + 多 Agent 编排（可复用 DSH 插件体系或 LangGraph 类方案）+ SQLite 落盘 + Bot 群聊视图。
  • 必须有的三个功能（只为演示效果服务）：① 一句话创建"团队"（主管 Bot 自动招募角色）；② 群聊里多 Bot 协作并在界面上可见；③ 每个 Bot 的职业记忆面板。
  • 刻意不做：账号体系、云同步、支付、多租户、权限体系。这些等你收到钱再说。
  • 并行准备好 3 支"演示编队"：从你选的垂类里挑 3 个具体场景，每个都要能跑通到"产出一个真实可用文件"（如一份选品报告 / 一份合同风险清单 / 一周 30 条选题）。
可运行 Demo3 支演示编队GitHub 仓库开源
阶段 2 · 内容矩阵冷启动（与阶段 1 并行，第 4 周起必须发）
第 4–10 周

这是赚到钱的分水岭。历史数据说明：赚到钱的不是技术最强的人，是最早把过程讲出来的人。

  • 三大内容系列（每条 1–3 分钟，坚持真人出镜/真声）：
    　① 《一个人 = 100 个员工》：用你的 Demo 演示一支完整编队跑完一个真实任务，主打视觉冲击；
    　② 《拆解一个岗位》：每期挑一个具体岗位（外贸询盘员 / 淘宝客服 / 法务助理），讲清楚哪几步可以交给编队、哪几步必须人来做；
    　③ 《踩坑实录》：真实翻车、Token 花超了、Agent 互相甩锅——这条线最涨粉，因为它证明你是真在做而不是在卖课。
  • 发布节奏：小红书日更图文（低成本）+ 视频号/B站周更 2 条长视频。前 8 周不要在乎播放量，只在乎"有没有 10 个精准的人在评论区问问题"。
  • 私域承接：所有内容导向一个免费社群（不发付费产品），社群只做三件事：答疑、发更新、征集下一个要拆解的岗位。
  • 内容合规：AI 生成内容必须按《人工智能生成合成内容标识办法》做显式/隐式标识；不要出现"AI 自动炒股""AI 帮你转账"这类表述。
每周 5–7 条内容免费社群 200+ 人至少 1 条破万播放
阶段 3 · 变现闭环
第 11–18 周

顺序很重要：先卖模板包（验证需求），再卖陪跑（做现金流）。不要一上来就卖课。

  • 首发利润品：行业编队模板包（定价 199–499 元）。交付物 = 角色定义文件 + 提示词 + 技能包 + 验收清单 + 30 分钟录屏。用第一支编队验证，跑通了再复制到第二、第三支。
  • 高客单层：编队落地陪跑（3000–50000 元/单）。走"先做 3–5 天 MVP 跑通核心流程 → 客户认可 → 再签正式交付"。获客来源必须是内容里主动来问的人，不要冷启动推销。
  • 验证指标先行：先设一个月度盈亏线，再决定是否加码。参考公式：
月固定成本 = 生活费 + 工具订阅 + 记账/主体维护
月必需营收 = 月固定成本 ÷ 毛利率
决策线：连续 3 个月净收入 ≥ 月必需营收 → 可考虑全职放大
  • 不要做的事：不要做代安装（门槛已消失）；不要卖"AI 快速致富课"（短命且伤 IP）；不要把收入结构建立在任何一家的模型补贴上。
模板包首月 50 单陪跑 2–4 单/月月收入覆盖固定成本
阶段 4 · 放大与生态合作
第 19–24 周及以后
  • 把"编队"做成可订阅的产品线：从一次性模板包升级为"每月新增 1 支编队 + 更新"的会员制，这是唯一能突破时间天花板的结构。
  • 大厂生态合作：当你在某一垂类有了信任度，主动接触 DSH / 豆包工作 / WorkBuddy / 千问办公的生态团队（它们都在做插件与开放平台），争取"生态讲师 / 认证开发者 / 联合案例"。这条路比单纯接广告健康得多。
  • 直播：把"直播搭建一支编队"做成固定栏目（参考傅盛直播养龙虾的路径）。直播真正的价值不是打赏，是实时答疑带来的信任转化。
  • 反脆弱设计：所有内容与模板的资产（账号、社群、案例库）独立于任何单一平台与技术栈存在。下一波技术浪潮来时，直接复用。
会员订阅制1 个官方生态身份资产可跨风口迁移

6.2 合规边界（必须知道，但不必害怕）

法规 / 文件生效时间对你的影响
《生成式人工智能服务管理暂行办法》及配套执行细则（三轨制：算法备案 / 大模型备案 / AI 应用登记） 2026.03 重点。面向公众提供生成式 AI 服务需备案。你的模式是"本地工具 + 人工服务"，不向公众提供在线生成服务，合规压力显著低于做 SaaS。这是本地优先路线被低估的一个优势。
《智能体规范应用与创新发展实施意见》 2026.05.08 重点。首次以"具备自主感知、记忆、决策、交互与执行能力的智能系统"定义智能体；要求决策可解释、人机协同审核、按场景分类分级、建立"备案—评估—应急处置"机制。你的编队方案里必须内置"高风险动作人工确认"的设计，这本来就是好产品设计，也顺便满足合规。

《人工智能拟人化互动服务管理暂行办法》 2026.07.15 若你的产品涉及拟人化陪伴/情感互动，需额外注意。建议编队定位为"工作执行体"，明确非人格化。

合规策略一句话

做"本地运行的软件工具 + 人工交付的服务"，不做"面向公众的在线 AI 服务"。前者几乎不触发备案义务，后者才是监管重点。你的"本地优先"路线在合规上反而是优势——这比它在成本上的优势更值钱，也更难被大厂复制（大厂做长尾服务时，合规成本会压垮单量）。

PART 08

最后：如果只带走三句话

第一句：方向对，但你已经晚了半步。国内大厂不是"即将跟进"，而是已经在打淘汰赛。这意味着你不能再用上一波的"信息差玩法"，只能走"能力差 + 信任差"。

第二句：这波的钥匙不是"做得更好"，是"讲得更清楚"。上一波赚到钱的不是技术最强的开发者，是最早把自己的踩坑过程变成内容的人——99 元教程两周 8 万、9.9 元教程日销几十单、傅盛直播养龙虾。你的 Demo 是道具，你的编队方案是商品，你的账号是资产。

第三句：今晚就可以开始，不用等 Demo。第一步不是写代码，是选定一个垂类、建好三个同名账号、发出第一条"我要用 AI 编队替代某一个具体岗位"的内容。窗口只有 8 周左右，而内容资产是唯一能跨风口带走的东西。
