## 一、结论先行

### 1.1 你的判断里，有三条需要修正

| 你的原判断 | 取证结论 | 修正 |
|---|---|---|
| "目前都是国外大厂在做，很快会刮到国内" | **错，且错得比较关键。** 国内大厂不仅已经在做，而且**已经打完赛马、进入整合淘汰期**：腾讯 QClaw 已于 2026-09-24 公告停运（12-24 零时），用户迁往 WorkBuddy；阿里 7 月把 QoderWork+悟空+MuleRun 三合一成"千问办公"；字节 8 月把 TRAE+扣子并入"豆包工作"；百度 8 月把内部 dodo 并入"搭子"。 | 你不是"抢在风口前"，而是"晚半步进场"。**信息差窗口已经关闭，能力差窗口还在。** |

### 1.2 一句话结论

> **方向成立，但你要做的不是"再造一个 OpenClaw"，而是"本地优先的多 Agent 编排层 + 行业编队方案 + 个人信任资产"。Demo 是钩子不是商品；真正卖钱的是"编队 Know-how"和"人肉交付"。**

### 1.3 三条最重要的行动判断

1. **第一利润品不是软件、不是课，是"行业编队模板包 + 企业陪跑"。** 取证显示"陪跑落地"是市场公认的溢价核心，且合规负担最轻（人工交付，不触发备案）。
2. **"开源 → 私域 → 付费"这条链条在国内没有任何可信的转化数据支撑，必须当假设验证，不能当收入预测。**（这是既有报告最乐观、也最缺乏证据的一环。）
3. **今晚就能开始的第一步不是写代码，是选定一个垂类 + 建三个同名账号 + 发出第一条内容。** 窗口在走，内容资产是唯一能跨风口带走的东西。

## 二、起点材料还原：这篇文章到底说了什么

### 2.1 事实层（已核实）

- **文章真实存在**，Datawhale 于 2026-10-11 发布，摘要为"一款基于 DeepSeek Harness 的 Bot 插件……装上它就能创建自己的 Bot 团队"。
- **它讲的是 DS Bot**（`github.com/Fei2411/DeepSeek-Bot`），作者 GitHub 用户 **Fei2411**（原名 FeiZhuLulu，媒体称 FeiZ），2026-10-07 建仓。
- **DS Bot 不是 DeepSeek 官方产品。** 其 README 原文："DS Bot is an independent community project. It is not an official DeepSeek product, and it is not affiliated with, endorsed by or sponsored by DeepSeek." Pandaily 报道同样写明非官方。
- **许可：Apache-2.0。** 最新 v0.1.2（2026-10-11）。Star 曲线：10-08 约 53 → 10-10 约 111 → **10-11 约 449 → 10-12 约 1,071**（star-history 反解，与 Pandaily 引量子位"一天 250+、10-11 过 450"吻合）。
- **底座 DSH 是 DeepSeek 官方项目**：`deepseek-ai/deepseek-harness`，**MIT**，**247,786★**，TypeScript，2026-08-13 创建，slogan "Everything is a Plugin."，基于 Cordis 插件框架，最新 v0.2.1-alpha.2（2026-10-09）。

> **标题党提示：** "DeepSeek Bot 发布"会让人以为是官方发布，实际是**社区插件事件**。这个区别很重要——它说明官方开放插件体系后，**48 小时内就能长出爆款**，生态位真实存在。

### 2.2 DS Bot 的机制（全部逐条核实为真）

| 机制 | 设计 | 产品意图 |
|---|---|---|
| **Chief 主 Bot** | 首次启动自动创建高权限主管 Bot，管理其他 Bot 与群聊；作者建议"别读文档，直接跟 Chief 说话" | 用对话替代配置界面，上手门槛压到接近零 |
| **群聊 + 管理员 Bot** | 每个群默认由 admin Bot 回复，需要时再 @ 调用其他 Bot | **直接解决多 Bot 齐刷刷回复导致的 Token 爆炸** |
| **长期记忆** | 每个 Bot 一份 Markdown 记忆文件 + 团队共享记忆；每轮由模型审查该记/改/删什么 | 把"重复交代"变成一次性设置 |
| **独立上下文** | 每个 Bot 对应一个 DSH session；超长时用压缩、交接摘要、SQLite FTS 本地全文检索 | 解决多 Agent 上下文管理 |
| **按 Bot 选模型** | 写手 Bot 与程序员 Bot 可用不同模型；Usage 按时间/Bot/模型统计 Token | 成本可见、按角色配算力 |
| **全本地存储** | 数据落在 `~/.dsh` 下 `bot/` 与 `sessions/`，卸载插件不删数据 | 隐私与数据主权 |

### 2.3 一个必须知道的风险信号

**DSH 官方自己已上线"智能体团队"（实验性）功能**——官网插件面板可见，代码库存在 `docs/subsystems/agent-team.md`、`packages/experimental/agent-team/`（含 TeamId、共享任务 DAG）。同时社区已有 `NanmiCoder/dsh-agent-teams`（2,040★，MIT）这类竞品插件。

> **含义：** "多 Agent 协同"这个能力**随时可能被官方一键收编**。这决定了你不能把价值押在"功能"上——功能会被官方吃掉，只有"编队方案 + 垂直人群信任"吃不掉。

### 4.2 大厂的真实动作是"收拢"而非"跟进"

2026 年 7–9 月是**大厂集中合并产品线**的四个月：

- 阿里：7 月 QoderWork + 悟空 + MuleRun 三合一 → 8-03 千问办公公测
- 字节：8 月 TRAE + 扣子并入豆包体系 → 推出"豆包工作"
- 百度：8 月内部 dodo 并入"搭子"；9 月文心快码并入

> 虎嗅 2026-09-24 的判断：**赛马阶段结束，进入定位赛**。这意味着窗口正在关闭，但也意味着**大厂不会再有"多线试错"的余裕去做长尾**。

### 4.3 大厂产品的共同短板（这就是你的空间）

1. **偏通用办公、云端为主**：交付物是文档/表格/PPT，核心算力在云，本地只做文件读写代理。
2. **强登录、强生态绑定**：豆包工作要飞书企业账号，千问办公闭环在钉钉，WorkBuddy 绑腾讯生态——**换生态即失效**。
3. **数据上云 + 权限让渡**：集中入口即集中记忆，用户上下文汇入厂商云。
4. **同质化严重**：三家产品定义、交付物、交互几乎同构，差异只在绑哪套 IM。

### 4.4 空位判断：成立，但比既有报告说的窄

**"本地运行 + 多 Agent 编排 + 不绑生态 + 数据不出本机"这个交集，目前没有大厂产品占位。**

证据链：
- 大厂**全部**选择"云端 + 生态绑定"路线，把本地执行当云产品的入口（腾讯甚至主动砍掉最本地化的 QClaw）。
- 唯一的本地优先开源产品 LobsterAI，定位是**单机办公助手**，多 Agent 编排不是其主打。
- OpenClaw（MIT，39 万★）已把"本地 Agent Runtime"这一层**商品化**——你不能靠它建壁垒，只能靠它之上的编排。

**窗口还剩多久：约 6–12 个月。** 风险点是 PC 厂商把本地 Agent 下沉到 OS/固件（华为 HarmonyOS 7 已示范），一旦发生，纯软件层的本地窗口会显著收窄。

### 5.4 修正版五条规律

1. **钱不在模型层，在"门槛差"上。** 门槛存在 → 服务溢价；门槛消失 → 生意归零。第一个问题永远是："门槛在哪，多久消失？"
2. **一次性服务退潮即归零，内容与信任留下。** 代装是一锤子买卖；阿凯的群、小鑫的账号退潮后仍有价值——它们沉淀的是"这个人懂行"的认知。
3. **热度窗口 8–10 周，认知窗口长得多。** 节奏：热度期抢内容，退潮期做产品。
4. **杀死上一波的不是产品缺陷，是"补贴结束"。** 2026 上半年 Agent 繁荣很大程度是模型厂商免费额度在买单；Anthropic 切断订阅后同涨同跌。**你的商业模式必须不依赖任何一家的补贴活着**——这正是"本地跑 + 用户自带额度"的真正价值。
5. **卖铲人内部也分层，越往上留存越久。** 正确做法不是选一层，而是**用 L2 的现金流养 L3/L5 的资产**。

| 用户心智 | "这玩意儿牛，我得试试" | "我该让这些 AI 员工替我干什么活" | 从功能好奇转向场景需求 |

### 反直觉但必须接受的结论

**"本地优先的多 Agent 产品 Demo"作为流量入口和信任凭证价值极高；作为收入来源几乎没有价值。**

原因：LobsterAI 已开源免费；DSH/OpenClaw 生态里的开源多 Agent 编排项目已有几十个；官方自己都在做"智能体团队"。**在"工具"这一层，开源免费是默认价格。**

> **正确定位：Demo 是钩子，不是商品。**

### 这一波真正的四个空位

1. **行业编队 Know-how**——大厂做通用办公，绝无可能去做"跨境电商选品三人组""独立律师助理团队"这类长尾编队。
2. **中文场景内容**——开源项目文档以英文为主，大厂内容偏"功能介绍"；缺的是"用大白话讲清楚一个具体岗位怎么被编队替代"。
3. **本地 + 自带模型的成本结构**——不依赖补贴，边际成本≈0。
4. **大厂不愿做的"人肉交付"**——企业侧真实需求是"帮我把流程跑通并教会我的人"，客单价几千到上万，非标长尾大厂不接。

## 八、技术方案（含许可红线与成本量化）

### 8.1 许可风险清单（商业化硬约束）

| 项目 | 许可 | 结论 |
|---|---|---|
| **DeepSeek Harness** | **MIT** | ✅ 可商用、可闭源改造 |
| **DS Bot** | **Apache-2.0** | ✅ 可商用（保留 NOTICE） |
| **OpenClaw / OpenClaw Enterprise** | **MIT** | ✅ 可商用（**但"OpenClaw"是商标，不能做产品名**） |
| **AgentTeams（`agentscope-ai/AgentTeams`）** | **Apache-2.0**（5,732★，Go，阿里 AgentScope） | ✅ 可商用 |
| ⚠️ **`777genius/agent-teams-ai`** | **AGPL-3.0**（2,254★） | ❌ **不可 fork 后闭源分发**。既有报告把这两个项目混为一谈（"Agent Teams 是 AGPL"），实际主流那个是 Apache-2.0。 |
| ⚠️ **obelisk** | **AGPL-3.0** | ❌ DS Bot 记忆检索思路的来源，只可学习设计 |
| ⚠️ **n8n** | Sustainable Use License（非开源） | ❌ 不能打包进付费产品 |
| ⚠️ **Dify** | 修改版 Apache-2.0 | ⚠️ 禁止多租户、禁止去 Logo |

**AGPL 会怎样咬你：** §13 网络条款——修改 AGPL 代码并通过网络提供服务，须向用户提供完整源码；§5/§6——与你的代码结合成单一作品分发，整个作品受 AGPL 约束。**只在本地自用、不分发、不提供网络服务则不触发。** 学习其架构、自己重写完全合法（思路不受版权保护）。

**推荐策略（法理上干净）：** 只做**编排层 + 技能包**（自己的原创代码，Apache-2.0 输出），底座由用户自行安装（DSH/OpenClaw/goose 都是 MIT/Apache），**你不构成"分发 AGPL 作品"**。做成"引导安装"而非"内置"。

### 8.2 推荐技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 桌面壳 | **Electron 44.7**（Demo）→ Tauri 2.12（v2 优化） | 4 周内速度优先，全栈 TS 一把梭；Tauri 留作体积/内存优化 |
| 本地后端 | Node.js + TypeScript | 与 Electron 同语言，`better-sqlite3` 原生可用 |
| 存储 | **SQLite + FTS5** | 内置 bm25/trigram/snippet，本地全文检索零依赖 |
| 编排 | **自研 Supervisor + 轻量 DAG** | 主管模式最易演示，逻辑存 SQLite 可恢复，规避 AGPL |
| 多 Agent 范式 | **主管 Bot + 群聊 + 管理员默认回复 + 按需 @** | 直接复用 DS Bot 已验证设计，天然控 Token |
| 记忆 | Markdown（事实来源）+ FTS5 召回，向量库列 v2 | 可读可版本化，零依赖 |
| 模型接入 | **BYO-Key 多 provider**：DeepSeek-flash 默认，Qwen/GLM 备选，Ollama 本地 | 边际成本≈0 |

**被否决：** n8n（SUL）、Dify（多租户限制）、777genius/agent-teams-ai（AGPL）、OpenClaw Enterprise（需 K8s，对桌面工具过重）、CrewAI/AutoGen/LangGraph 直接做底座（服务端 Python，非桌面）、自建代理转发（边际成本非零 + 可能触发资质问题）。

### 8.3 成本量化（这是"用户自带额度"模式的核心优势）

**现行价格（人民币/百万 tokens，2026-10-12 官方抓取）：**

| 模型 | 输入（缓存命中/未命中） | 输出 |
|---|---|---|
| DeepSeek-flash | ¥0.02 / ¥1（闲时） | ¥4 |
| Qwen3.8-flash | ¥0.8 | ¥2.7 |
| GLM-5.3-Flash | ¥0.8 | ¥2.8 |
| Kimi K3 | ¥2 | ¥100 |
| Claude 中档（$2/$10） | — | 约 ¥3.99/¥7.98 折算 |

**一次多 Agent 任务的成本（估算模型）：**

| 场景 | 角色数 | 调用次数 | 总输入 | 总输出 |
|---|---|---|---|---|
| 中等（写一份竞品分析） | 6 | 4 | ~192K | ~17K |
| 重度（完整内容运营闭环） | 12 | 8 | ~1.44M | ~77K |

- 中等任务用 **DeepSeek-flash 闲时 ≈ ¥0.26**、峰时 ¥0.52；用 Claude 中档 ≈ ¥3.99。
- 重度任务用 **DeepSeek-flash 闲时 ≈ ¥1.75**、峰时 ¥3.50；用 Kimi K3 / GPT 中高档 **¥10–30**。

**结论：flash 级国产模型无论中等还是重度任务都稳稳 <¥5；这是"默认便宜模型 + 按需升级"的直接价值。**

**"用户自带额度"下你的边际成本 ≈ ¥0**（仅更新检查/可选遥测的服务器成本，可低至每月几十元）。**建议不做代理转发**——那会承担模型成本、需要计量风控，还可能触发资质问题。

**把单次任务压到 ¥5 以内的七个手法：**
1. 默认 flash 级模型，仅主管/汇总用强模型
2. **强制开启上下文缓存**（DeepSeek 缓存命中价是未命中的 1/50；前缀稳定化可极大提高命中率）
3. 管理员 Bot 默认回复 + 按需调用
4. 交接摘要 + FTS5 按需召回，不塞全文历史
5. 输出上限 + 非思考模式
6. 按复杂度路由（ClawRouter 思路）
7. off-peak 批处理（DeepSeek 空闲时段半价）

### 8.4 本地模型可行性

- 当前 Mac mini 已更新为 **M6 / M5 Pro**（M4 已不在售）；M6 上限 32GB，M5 Pro 上限 64GB。
- **32GB M6 可流畅跑 qwen3.5:27b（17GB）/ 35b（22GB）/ gemma4:31b（19GB）**，这些支持工具调用，足够支撑 Agent 编排。
- **最优解是混合模式**：本地做记忆/召回/简单工具调用，云端做强推理。

### 9.1 90 天作战计划（紧凑版）

**第 1–14 天 · 定位与第一个可录屏 Demo**

- 选一个垂类（**全案最重要的一次决策**）。筛选标准：① 反复做重复性工作；② 已在用 AI 但不满意；③ 有明确付费习惯。候选：跨境电商小卖家、独立律师/会计、小红书 MCN、外贸 SOHO、SaaS 独立开发者、本地生活商家。
- 盘点存量优势：你做过哪些行业？有哪些现成人脉？**第一支编队必须长在你已有的认知上**，否则内容会空。
- 技术底座选型 + 许可核对（优先 DSH）。
- 用现有开源框架组装一个可运行工作流，每天记录：输入、Agent 分工、调用模型、耗时、Token、人工介入、结果。
- 建三个同名账号（小红书 + 视频号 + GitHub），攒 30 条观点选题。
- 发布 10 条内容，主题"我用一人公司养 8 个 AI 员工的一周"，每条只讲一个具体任务 + 一个失败教训。

> **验收：** 陌生用户看完 3 分钟视频后，能说清"谁负责什么、为什么需要多个 Agent、最后省了什么、花了多少钱"。

**第 15–30 天 · 产品壳 + 3 个模板**

- 把能力包装成桌面/本地 Web 应用：安装器、模型配置、团队模板、日志、权限、恢复。
- 首批只做三个模板：**内容增长团队 / 独立开发者销售团队 / 产品研发团队**。
- 招 10–20 名种子用户（独立开发者、内容创业者、咨询顾问、小工作室），免费换使用记录和访谈，**不承诺"自动赚钱"**。

**第 31–60 天 · 从 Demo 到可交付套餐**

| 套餐 | 定价 | 内容 |
|---|---|---|
| 体验版 | 免费/低价 | 基础团队模板 + 公开教程 |
| 个人 Pro | 49–199 元/月 | 更多模板、版本更新、使用统计、社区支持 |
| 一对一交付 | 999–2999 元（首批） | 本地安装 + 模型配置 + 一个业务工作流定制 + 培训 |

> 价格不是市场事实，是**验证起点**。真正重要的是记录：转化率、交付耗时、退款原因、用户每周实际运行次数、愿意重复付费的功能。

**第 61–90 天 · 用数据定主航道**

- 播放高但没人试用 → 叙事有吸引力，产品价值不清楚。
- 试用多但复用低 → Demo 好看但工作流不稳定/不够刚需。
- 愿付交付费但不愿订阅 → 你更适合做垂直服务与实施。
- 主动分享模板并愿持续更新 → 才考虑模板市场/插件生态。

> **90 天结束时，最多保留一个主垂类 + 一个次垂类。** 不要变成"什么行业都能做的 AI 外包公司"。

```
月固定成本 = 生活费 + 工具订阅 + 记账/主体维护
月必需营收 = 月固定成本 ÷ 毛利率
决策线：连续 3 个月净收入 ≥ 月必需营收 → 可考虑全职放大
```

**不要做的事：** 不要做代安装（门槛已消失）；不要卖"AI 快速致富课"（短命且伤 IP）；不要把收入结构建立在任何一家的模型补贴上。

## 十、变现路径 ROI 排序（修正版）

> **重要：** 既有报告把"内容引流 + 免费社群"和"模板包"列为 P0，把"企业陪跑"列为 P1。**本次取证建议把顺序反过来**——因为"内容→付费"的转化链条在国内**没有任何可信数据**，而"陪跑落地"是市场公认的溢价核心且合规负担最轻。

| 优先级 | 路径 | 启动难度 | 回款速度 | 生命周期 | 依据强度 |
|---|---|---|---|---|---|
| **P0** | **企业陪跑/咨询**（3000–5万/单） | 中（需案例+信任） | **快** | 中 | **强**（多来源一致：陪跑是溢价核心） |
| **P0** | **行业编队模板包**（199–499） | 中 | 快 | **长**（可复用、边际成本低） | 中 |
| P1 | 开源项目做 IP（GitHub→私域→付费） | **高**（长周期） | **慢** | 长 | **弱（无实证数据，待验证假设）** |
| P1 | 内容引流 + 免费社群 | 低 | 中 | 长 | 中（是前提，但转化率无据） |
| P2 | 中价教程（99–199） | 低 | 快 | 中 | 中 |
| P3 | 会员订阅（每月新编队） | 中 | 中 | 长 | 中（前提是模板包已跑通） |
| P3 | 大厂生态合作/推广 | **高**（个人入口窄） | 慢 | 中 | 中 |
| ⛔ | 代安装 / 卸载 / 速成致富课 | 低 | 极快 | 极短 | — |

**排序逻辑：按"现金流确定性 × 合规安全度"。** 企业陪跑回款快、合规负担轻（人工交付、不碰备案），是当前最优解；开源做 IP 是**长期钩子**而非近期现金流。

> **必须诚实面对的一条：** 我未找到任何国内"开源 GitHub star → 私域 → 付费"的可信转化数据，也未找到官方（艾瑞/易观/CNNIC）发布的 2025–2026 知识付费转化率基准。**所有"转化率 3%""1000 精准粉 > 100 万泛粉"这类说法都来自自媒体营销话术。** 请把这条链条当假设验证，不要拿它做收入预测。

### 11.2 你的合规定性

**"本地运行的软件工具 + 人工交付的服务" vs "面向公众的在线 AI 服务"——这条线决定你的一切。**

- ✅ **大概率不触发备案**：Demo 免费开源、用户在自己机器本地运行、你不运营托管服务、你交付的是咨询（人脑输出）。落在第二条豁免区。
- ⚠️ **可能触发**：一旦你**托管运营**让公众在线调用的 Agent 服务，或模板包内置了**你提供的大模型能力**并对外服务 → 至少需要大模型登记 + 算法备案。
- **"人工交付"不改变定性，改变定性的是"是否提供 AI 服务本身"。**

> **合规策略一句话：** 做"本地运行的软件工具 + 人工交付的服务"，不做"面向公众的在线 AI 服务"。**你的"本地优先"路线在合规上反而是优势——这比它在成本上的优势更值钱，也更难被大厂复制。**

### 11.3 必须避免的红线

1. ❌ **托管运营面向公众的生成式 AI 服务**（尤其自研模型）→ 大模型备案 3–6 个月 + 算法备案
2. ❌ **未标识的 AI 生成内容**：小红书已自动检测 + 限流，抖音最高封号。**演示视频/图文必须显式标识**
3. ❌ **"AI 炒股 / AI 帮你转账 / 稳赚不赔"**：武汉市 2026-03-16 专门警示；21 世纪经济报道 2026-06-12 曝光借小红书/短视频行骗套路。**平台违规 + 金融违法双线**
4. ❌ **私信/评论区主动留微信、二维码导流**：小红书"恶意导流最严封号"
5. ❌ **做拟人化情感陪伴/虚拟伴侣**（尤其面向未成年人）
6. ❌ **把"核定征收 0.5%"当政策承诺**
7. ❌ **删除/篡改/隐匿 AI 标识**
8. ❌ **忽视技能包/插件供应链安全**

## 十四、最后：如果只带走三句话

1. **方向对，但你已经晚了半步。** 国内大厂不是"即将跟进"，而是已经在打淘汰赛（QClaw 已停运）。这意味着你不能用上一波的"信息差玩法"，只能走"能力差 + 信任差"。
