# OneFleet 发布视频分镜脚本

> 时长目标：90-120 秒（社媒版）/ 可剪 3 分钟完整版
> 核心叙事：**把一支 AI 机器人编队装进电脑，再用微信随时随地指挥它**
> 两个高潮镜头：① 导入模板一键建队 ② 微信扫码手机遥控

## 分镜

### 镜头 1 · 开场钩子（0:00-0:08）

- 画面：黑屏 → OneFleet 章鱼 logo 浮现 → 主界面三栏布局
- 字幕/口播：「你有一支 AI 员工队伍，但现在你只能坐在电脑前指挥它们——直到现在。」
- 备注：前 3 秒必须出现产品界面，社媒划走率全看这里

### 镜头 2 · 一键建队（0:08-0:30）

- 画面操作序列：
  1. 点左侧「编队」→ 点「导入编队模板」
  2. 选择 `competitor-radar.yaml`（竞品雷达编队）
  3. 会话瞬间创建：3 个机器人的群聊出现，欢迎任务自动发出
  4. 状态灯亮起（绿色呼吸环），调研员开始干活，写手/审查员接力
- 字幕：「一份 YAML，三秒建队：调研员、写手、审查员，各司其职。」
- 备注：素材已有（W3 E2E 录屏）；建议提前把任务量造大一点，能看到交付物卡产出

### 镜头 3 · 微信扫码（0:30-0:50）★高潮一

- 画面操作序列：
  1. 点左侧微信图标「远程」→ 右栏出现微信管理页
  2. 点「扫码接入微信」→ 二维码
  3. **切手机实拍**：微信扫一扫 → 确认登录
  4. 电脑屏幕：状态翻「已连接」，选择值班机器人
- 字幕：「扫码。你的机器人编队，从此装进了微信。」
- 备注：手机+电脑双机位或画中画；二维码 120s 过期，录前先练一遍流程

### 镜头 4 · 手机遥控（0:50-1:15）★高潮二

- 画面操作序列：
  1. 手机微信里给机器人发：「帮我看看今天有什么值得复盘的」
  2. 电脑端：消息出现在机器人 DM，状态灯转绿开始工作
  3. 微信顶部出现「对方正在输入…」
  4. 手机收到机器人的完整回复
- 字幕：「通勤路上发一条，回家收获一份完整复盘。你的 AI 员工，下班也在线。」
- 备注：这是情绪价值最高的一镜；typing 指示一定要拍到（细节说服力）

### 镜头 5 · 交付物与成本（1:15-1:35，可选）

- 画面：会话里的交付物卡（点击可打开文件）+ 成本里程碑卡（累计 tokens）
- 字幕：「干了什么活、花了多少 token，全部看得见。」
- 备注：本地优先、数据不出电脑，隐私卖点顺口带一句

### 镜头 6 · 收尾 CTA（1:35-1:50）

- 画面：GitHub 仓库页 / 下载页 → logo + slogan
- 字幕：「OneFleet —— 一人公司的机器人舰队。开源，本地优先，扫码即用。」
- 备注：挂仓库链接；评论区置顶使用教程

## 录制前 checklist

- [ ] fresh 环境：对话列表清到只留演示需要的 1-2 条
- [ ] 模型配置确认（GLM key 有效、账户余额充足）
- [ ] 微信**提前扫码录镜头 3**（每次扫码 bot_id 会变，中途重连会产生两个机器人对话）
- [ ] 二维码过期自动刷新已验证；录 3 时若过期点「刷新二维码」剪掉即可
- [ ] 分辨率 2560x1600 @30fps，鼠标放大 1.5x（细节可读）
- [ ] 手机端录屏 1080p 竖屏，后面画中画合成
