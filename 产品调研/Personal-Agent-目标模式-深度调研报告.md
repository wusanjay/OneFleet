## 0. 摘要（TL;DR）

1. **品类已确认爆发**。2026 年 6–10 月四个月内，xAI（/goal + Grok Bot，8-11）、Meta（Muse，9-8）、Manus（2.0 + Cue，9-28）、OpenAI（dots，9-29）、Anthropic（Claude Duet，10-21）密集发布同一范式产品：**目标模式（Goal Mode）**——用户设定目标，agent 在专属算力上长时间自主执行、主动汇报。Meta Muse 40 天 1000 万美国下载、2.5M DAU，验证了消费级需求。
2. **五家全部采用"云 VM 重资产"架构，无一例外，且这块地是被主动让出来的**。腾讯 LightVela（云端 Agent 托管，2026-09-26 上线）官方文档明确把"要求完全本地运行、数据不离开终端的用户"列为不适合人群——这是"大厂书面放弃本地"的最硬证据（本地 = 无法收集数据 = 无法形成记忆飞轮 = 无法卖订阅，是商业模式决定的结构性放弃）。成本侧：第三方测算 1 亿用户规模下 Muse 需 1.63GW 电力、Grok Bot 需 5.97GW；$20/月订阅撑不起常驻 VM（盈亏平衡需 23–38% 付费率）。**这就是本地化产品的结构性切入口**。Perplexity Computer（2026-08 转向 local-first，DGX Spark $4,679）已验证需求，但硬件门槛太高——**胜负手是在消费级硬件上跑出可用的 agent 栈**。
3. **OpenClaw 风口的国内赚钱复盘结论：信息差生意（代装/低价课）窗口只有 2–4 周且已被监管点名；真正穿越热度周期的钱在三处——ToB「部署+治理+Token 成本优化」交付（"凉了反而更忙"）、沉淀私域的付费社群、可迁移的内容资产**。已有可检索的实名案例锚点：99 元教程 2 周 800+ 份≈8 万元（阿凯）、企业定制单笔 8000 元外贸竞品监控（李岸）、Skill 订阅 20 天 400+ 付费用户月纯利 1 万+（Jimmy）。
4. **技术上不存在需要从零发明的东西**。九个开源仓库（openclaw / pi / hermes-agent / Orkas / ZCode / deepseek-harness / DeepSeek-Bot / dsh-agent-teams / tarocub，全部 MIT/Apache-2.0 可商用）合起来已覆盖目标模式、多 Agent 群协作、分层记忆、渠道网关、插件生态全部五个核心能力。**必须自研的只有四件：微信单入口多角色路由、全局记忆作用域仲裁、目标模式的产品化闭环、数据流向审计面板**——而这几件恰好是产品差异化所在。
5. **微信单入口约束有正解，且死心得更彻底**：iLink 协议不推送群消息事件，多员工群聊在微信里连做的可能性都没有。正解是"**微信 = 遥控器，办公室在别处**"——ClawBot 官方插件（个人免资质、扫码即用）做 C 端单聊遥控入口；多数字员工群协作放本地控制台与飞书；需要"一号一员工"形态时用**企业微信·微信客服（一家企业最多 5000 个客服账号，微信侧免加好友扫码即聊）**承接——这是 SCRM 行业规模化验证过的形态。个人微信 Hook/iPad 协议封号极高危 + 已有项目"被法务干了"，禁用。
6. **记忆是当前所有产品（含大厂）的最大短板，也是你的机会**：OpenAI dots 记忆完全黑盒被打 4.8/10，Claude Duet"很精致但用户会忘记用"，连 Meta Muse 都在删除诚实性上翻车。本报告给出**五层文件式记忆架构**（全局画像 / 组织 / 项目 / 角色 / 情景日记）完整设计，含防投毒行动门控（TMA-NM 方案，实测 0% 攻击成功率）与 ZCode Dream 式"冲突只标注、交人裁决"的整合铁律。
7. **拟人员工机器人 vs 智能体的关系**，行业已收敛出答案：**智能体 = 模板（persona + 技能 + 权限 + 模型配置），数字员工 = 实例（独立身份 + 私有记忆 + 渠道绑定 + 账号）**。Grok Bot（共享群聊上下文 + 每 bot 私有记忆）、Manus Cue（每 agent 独立邮箱/电话/钱包/电脑）、开源 DeepSeek-Bot（每成员每群一个隐藏会话）三家殊途同归。由此推出**本地架构最锋利的一刀：「100 个数字员工 = 1 个模板 × N 组参数」**——销售模板 × 100 个客户 = 100 个各自记住不同客户的专员；这在 Cue 架构下是成本灾难（每 agent 一台云电脑），在本地几乎零成本。
8. **变现主轴建议**：私有化/工作流交付（现金流，199–999 元小单引流 + 1–10 万中单赚钱，垂直行业首选外贸）→ 付费社群（199–2000 元/年，复利）→ 训练营（2000–6000 元，利润）→ 轻量订阅（补充）；**新增两条 2026-10 打开的通道：腾讯 WorkBuddy「收入变现」上架付费技能（内测期平台服务费仅 1%，个人开发者首次能在桌面 Agent 生态合规收 C 端钱）与阿里百炼 AI 打赏（开发者得 85%+）**。内容主轴：小红书做主战场（垂类商单实价：20 万粉 AI 博主图文 4.5 万/条、视频 8 万/条）+ B 站源码级长视频做信任背书 + 视频号私域承接；内容公式「**一个真实任务 + 本地跑 + 成本对比 + 数据流向截图**」——大厂做不了的内容，它们不能公开讲"我的数据上了云"。

## 1. 品类定义：目标模式（Goal Mode）与 Personal Agent

### 1.1 范式定义

Goal Mode 是从"指令-响应"到"目标-托管"的迁移，五个必备要素（五家大厂产品全部具备）：

| 要素 | 说明 | 典型实现 |
|---|---|---|
| 目标声明 | 一句话或多轮澄清式设定目标，而非逐条指令 | xAI `/goal Migrate the auth module…`、Codex goal mode、Muse"减掉啤酒肚"式生活目标 |
| 自主长时执行 | agent 获得专属算力与凭据，关掉客户端继续跑 | 每家都给 agent 配独立云 VM（Muse Secure VM、dots cloud computer、Duet 云电脑、Grok Bot cloud computer、Manus Cloud Computer） |
| 汇报协议 | checklist / 每日简报 / 频道式推送 / 审批推送 | Duet 每日晨报、dots Activity View |
| 审计 | 完整操作轨迹、可围观"agent 的电脑"、结论带来源引用 | dots 可开屏围观、Duet 数字引用来源邮件/文件 |
| 干预面 | pause / resume / redirect / clear | Codex 与 xAI /goal 已命令化 |

与相邻品类的分界：聊天助手（单次对话、会话内记忆）→ 工作流自动化（事件触发、无记忆）→ Coding Agent（任务制、项目级记忆）→ **Personal Agent（目标/偏好触发、常驻跨会话、专属算力、跨会话长期记忆）**。

演进脉络：Chatbot（2023）→ Assistant/工作流（2024–25）→ **OpenClaw 前奏（2025 末–2026 初，本地个人助手验证了"接入聊天渠道的常驻 agent"需求）** → Personal Agent 目标模式（2026 下半年大厂收割）。

爆发的三个前提同时成熟：模型侧长程推理到位（Opus 5.5 级别的长文本逻辑连贯）；成本侧 Cascade 类框架把 token/时间/成本降 23%/28%/32%；入口侧——一旦用户把邮件、日历、文件、业务系统接进 Agent，迁移成本骤增，这是入口级战争（Gartner：全球 AI 智能体支出 2025 年 164.8 亿 → 2027 年 654.7 亿美元）。

### 1.2 时间线速览

- 2025-11-24 OpenClaw（前身 Clawd/CLAWDIS/Clawdbot）发布，2026-01 全球爆火，7 天破 10 万 GitHub star，3 月初 25.3 万星超越 React
- 2025-12 Meta 宣布约 20 亿美元收购 Manus；**2026-04 该交易被中国监管（外商投资安全审查）叫停**，Manus 创始团队联合腾讯/红杉/真格按 20 亿美元估值回购全部股份（腾讯成最大外部股东），09-01 恢复独立运营，10-08 完成博裕/IDG 领投的超 5 亿美元融资（估值约 40 亿美元，国内 AI Agent 创企纪录）
- 2026-02-14 OpenClaw 作者 Steinberger 加入 OpenAI；2026-03-10 Meta 收购 agent 社交网络 Moltbook（150 万+ agent，建在 OpenClaw 上）
- 2026-06-22 xAI 发布 /goal；08-11 Grok Bot beta
- 2026-09-08 Meta Muse；09-28 Manus 2.0 + Cue；09-29 OpenAI dots（GPT-6 Astra DevDay）；10-21 Claude Duet research preview
- 国内跟进：2026-02-18 Kimi Claw → 06-18 Kimi Work Goal Mode；03-09 字节 ArkClaw；智谱 AutoClaw；MiniMax MaxClaw；**腾讯"做宿主平台不做龙虾"：微信 ClawBot（03-22）、QQ Bot（03-31）、WorkBuddy 开放平台（09-02，首批 100+ 伙伴）、LightVela 云端托管（09-26，明确排除本地需求用户）、QClaw 公告 12-24 停运（用户迁移 WorkBuddy）**；10-13 阿里千问 Go 内嵌千问 App 分批开放；10-11 蚂蚁灵光内测；10-14 字节豆包手机助手 SAEP 协议公示期满，**151 个应用声明拒绝被自动化操作**（生态围墙成型）

## 2. 五大厂产品对标

### 2.1 逐产品要点

**Meta Muse（2026-09-08）**——"第一款为所有人打造的个人 AI Agent"。
- 入口：iOS/Android/Web/**WhatsApp 内直接对话**；AI 眼镜唤醒、专属邮箱地址在路上。
- 架构：每用户一台 **Secure VM** + 同机隔离驻留 **Sentinel 监管 agent**（"Muse 的任何动作不经 Sentinel 批准不出网"）；预告用户持钥的 Confidential VM。
- 数据：40 天 1000 万美国下载（历史仅 ~11 款 App 达成）、2.5M DAU；同期 ChatGPT 美国下载下滑 25%。**但留存呈"前高后低"：首日留存约为 ChatGPT 两倍，14 日留存 22.5% 却低于 ChatGPT 的 26.8%**——留存是这个品类的分水岭，产品必须在一周内让用户看到一次"它真的替我办成了一件事"。
- 定价：免费（每周最高 1 亿 token）+ Power $20 + Maximum $100。
- 记忆：**markdown 文件式，用户可通过文件浏览器直接查看**（大厂第一家把文件式记忆当卖点）；但 TIME 曝光其"遗忘"不删除原始消息且内部指令要求不告知用户——删除诚实性反面教材。
- 支付：首个被 Stripe Link 一次性卡保护覆盖的 agent。
- 负面：09-20 起被亚马逊封禁访问；09-25 被曝 VM 安全漏洞；EPIC 批评文《Meta's Mass Data Collection Is Not A-Muse-ing》。

**OpenAI dots（2026-09-29）**——"每个 dot 一台云电脑"的 always-on 代理。
- 每 dot 独立云电脑 + 浏览器；**Proactive research：用户不在场时以只读模式找活干**（代码级强制，非 prompt 约束）；Auto-review 控制面放在 dot 不可触及处；本地电脑接入可选、默认关闭。
- 生态：4000+ 应用插件；与微软 Agent 365 治理层合作；specialist dots（独立身份）预览。
- 定价：首个 dot 含于 Pro / Business Premium（~$125/人/月），首月不计用量。
- 口碑：当前最弱——"incredibly slow and lazy"、"totally worthless"、有用户的 dot 已退化丢任务；**记忆完全黑盒**（官方明确无法查看/删除/修改单条记忆），第三方打 4.8/10。

**Claude Duet（2026-10-21，research preview，仅美国）**——知识工作者的"AI 首席参谋"。
- 每**人**一台云电脑；每日晨报（扫邮件+日历、起草回复）；按间隔检查账户；**"只有你能把任务标为完成"**；审批门（发消息/付款/签文档/删除前必问）；结论带来源引用。
- 记忆：与 Claude 主账号记忆/skills/连接器全量携带；**account + project 双层作用域**（项目内叠加账户记忆但永不跨项目）；实时保存为逐条主题条目，可查看/编辑/删除；健康/政治等敏感类目默认不存需 opt-in；检索带"为什么想起这条"引用链。**当前业界最完善的记忆产品设计**。
- 槽点：烧 ChatGPT 同款 5 小时/周额度（后台晨报也计费）；Lenny's Newsletter 标题即结论：**"Claude Duet is beautiful. I still forgot to use it"**；Every.to 称其为"第一个可称为专业工具的个人 agent"。
- **对中国用户三重不可用**：云端（数据给 Anthropic）、美国限定+候补、订阅烧额度——恰好是本地产品可正面打的三个点。

**xAI Grok Bot（2026-08-11 beta）+ /goal（2026-06-22）**——"AI 队友"隐喻。
- /goal：一行目标 → 规划 → progress checklist → 自主执行直到验证通过；`/goal status` 实时面板。
- 每账户**一台共享云电脑**（bot 共用文件/浏览器/登录，隔离 per user 非 per bot，xAI 文档明说"不要把不同的 Bot 当作安全边界"）；**Teaching mode（品类独有）**：演示一遍工作流 → 存为 routine → 之后定时自主执行（案例：销售 Bot 凌晨自动起草 36 封个性化邮件，未经批准一封不发）。
- **多 bot 团队**：2–6 个 bot 同一线程协作、互相 handoff；记忆模型 = **群聊/项目线程提供共享上下文 + 每 bot 私有持久记忆**（消费级第一个跑通"bot 团队"心智）。
- 定价：随 X 订阅 $30/$100/$200；**超出周额度按模型和 token 直接计费，且目前没有 Grok Bot 专属支出上限**；无 SOC 2/ISO 27001/GDPR/HIPAA/FedRAMP 任何认证——对受监管行业是硬阻断。
- 名言："**Told is last year. Done is the frontier.**"

**Manus 2.0 + Cue（2026-09-28）**——数字员工终局形态，且已独立、来势更猛。
- 公司轨迹：2025-12 Meta 宣布收购（ARR 已破 1 亿美元）→ **2026-04-27 被外商投资安全审查禁止** → 团队联合腾讯/红杉/真格按 20 亿美元回购 → 09-01 恢复独立运营 → **10-08 完成超 5 亿美元融资（博裕/IDG 领投，腾讯/红杉/真格跟投），估值约 40 亿美元**，ARR 升至 4–5 亿美元；**正在组建国内产品团队（17 个岗位全在北京），与国产模型厂商合作推进中**。
- Manus 2.0：Cascade 新 harness（官方数据 -23.2% tokens / -28.2% 时间 / -32% 成本）、Cloud Computer、Automations（事件触发器：新邮件/数据变化/日历/Slack/Notion）、Studio 桌面版（Remote Control 数据留本机——本地化信号）。
- **Cue：每个 agent 独立数字身份——自己的邮箱、电话号码、钱包、电脑**；多 agent 拉群围绕共享目标分工接力；预算内自主付款；与线下二维码打通。创始人肖弘："一个有独立的手机号、邮箱、支付、电脑和足够'智能'的'东西'，也许可以称之为'人'。"
- 商业化想象不止订阅：**替用户花钱的交易抽佣**（同赛道 Instinct 平台年化交易额已近 10 亿美元、超一半来自旅游预订）。
- 风险：VM 权限过宽史、prompt injection 漏洞（Dark Reading）、VerifyWise 信任指数 C 级；用户反馈的体验断点：已连 Gmail 却默认用自己的邮箱发信。
- **对你的含义**：Cue 验证了你的产品概念（"一人公司 + 数字员工拉群"几乎是 Cue 的中文版），但它的三个盲区就是你的差异化空间：① 全部云端；② 国内版尚未落地（窗口）；③ **每 agent 一套邮箱/电话/云电脑的成本随数量线性甚至超线性增长，开到 100 个在经济上不可行——而"100 个"在本地架构下边际成本趋近于零**。

### 2.3 云端重资产成本结构——本地化的切入口

Next Signal Prediction 测算（2026-09-24）：
- 单 VM：Muse ≈ 2 vCPU/8GB；Grok Bot ≈ 8 vCPU/15GiB（实测 idle 仅 1.6GiB——**空闲浪费是常态**）。
- 1 亿用户：Muse 需 ~78 万台服务器 / **1.63GW**；Grok Bot 需 312.5 万台 / **5.97GW**；内存需求相当于全球年 DRAM 产能的 1% 至更高量级。CPU 正在成为新瓶颈（AMD 年出货服务器 CPU 仅 ~1000 万颗）。
- 单位经济学：1 亿台常驻 Muse VM ≈ $300–500 亿 capex → 年折旧 $55–91 亿；1000 万人付 $20/月只覆盖折旧的 26–44%，**盈亏平衡需 23–38% 付费率（未含电费与推理）**。三家都设 $100–200 档并非巧合。
- 行业解法：把"常驻"做成"语义常驻、物理按需"（空闲回收/snapshot）——大厂在前端看不见的地方打成本战。

**对本地化产品的含义**：本地运行把 VM 边际成本归零、把隐私从"信任税"变成产品卖点，且天然不存在 idle 回收问题；消费级硬件（Mac mini / 普通笔记本）+ 用户自持云端 API key 的混合架构，就能把"每人每月 $20–125 的订阅"变成"一台机器一次买断"。**国内大厂的书面证据进一步坐实这块空地：腾讯 LightVela 官方文档明确把"要求完全本地运行、数据不离开终端的用户"列为不适合人群；千问 Go、豆包工作、灵光全部云端执行——不是做不了，是不想做（本地无法形成数据回收与订阅计费的商业模式）。**

### 3.5 监管与生态判定：对本地化产品整体是利好，但划定了产品边界

- **利好面**：《生成式人工智能服务管理暂行办法》第 2 条第 3 款明确**排除"未向境内公众提供服务"的场景**——纯本地自用/企业内部部署不触发备案义务，天然合规洼地；"数据不出域"契合数安法/个保法叙事。地方真金白银：深圳龙岗"龙虾十条"最高 200 万补贴。工信部 NVDB 的三次预警（2-05/3-11/3-31）本质是**在规训本地 Agent 而非禁止**——对按"六要六不要"标准设计（默认不暴露公网、最小权限、日志留存、高危命令黑名单）的产品反而是竞争门槛。
- **产品边界（SAEP 围墙）**：字节 SAEP 公示结果是终局性信号——**"替你操作第三方 App"这条路在中国走不通**（151 个头部应用拒绝 + 逆向协议封号/刑事风险）。正确方向是**本地文件、代码、知识库、私有数据、可脚本化的内部系统**——不需要任何第三方许可的场景，也正是 OpenClaw 深度用户真正留下来的价值区。
- **障碍面**：一旦对外提供 SaaS/订阅，需叠加模型备案或调用登记（接境外模型无法登记）、算法备案、ICP、AI 生成内容标识。**OPC 的生存空间恰好在"个人自托管"这个大厂不愿深耕、监管不要求的缝隙里。**
- 个人副业灰区：代装、中转 Key 属无资质经营，监管已点名；传播非官方安装包可能触及刑事风险。

| **tarocub**（16M） | 飞书优先本地 agent 网关 | 唯一执行核 seam（所有入口汇入同一授权消息路径）；飞书落地全流程（wizard 扫码注册/provision 补权限/tool tag 出站协议）；durable session `/resume` 跨设备续接；JSON store + 文件锁 + timeline/audit 审计 | MIT |

### 4.2 横向结论

五个核心能力在开源界**错开分布、无一仓库五项全优**：记忆最强 = openclaw；目标模式 judge 循环最强 = hermes（内核原语最干净 = dsh 的 goal/schedule/agent-team 三包）；拉群协作 = ds-bot + agent-teams + Orkas；中文渠道规格 = ZCode bots 文档 + tarocub 飞书 + hermes 26 平台；最小内核 = pi（扩展点完备性唯一全 PASS）。

### 4.3 推荐技术栈组合（方案 A，推荐）

**内核用 dsh（deepseek-harness），loop 参考 pi，记忆规格抄 openclaw + 作用域抄 ds-bot，目标模式抄 hermes goals + dsh goal/schedule，拉群协作抄 ds-bot + dsh-agent-teams + Orkas planner，飞书落地抄 tarocub + ZCode bots 规格；微信多角色路由、三层记忆仲裁、数据流向面板自研。**

理由：① Cordis "一切皆插件"是九仓库中最干净、最可长期维护的扩展模型；② session log = 唯一事实源直接解决 durable session 与审计回放——这也是"数据主权可验证"的技术底座；③ goal/schedule/subagent/agent-team/skill/sandbox 官方包齐全，桌面与 Web 双形态现成；④ 中文大厂出品、文档双语、MIT。若产品核心逻辑需要在工具执行前后插自定义治理（成本熔断/审批/出境拦截），pi 是备选 loop 层（EXP-000 七判据唯一全 PASS）。

**引擎可插拔设计**（关键架构决策）：像 tarocub"驱动真实 CLI"一样，把 openclaw / pi / dsh 都做成可插拔引擎适配层——用户可选用哪个内核，OneFleet 的差异化层（角色/记忆/路由/目标模式 UI/审计面板）建在引擎之上。这样既不必 fork 重仓库跟随升级，又能白嫖各引擎演进。

备选方案 B：直接以 openclaw 为运行时底座做插件（渠道/记忆/调度全白得），自研收敛为角色层 + 微信多角色路由 + 目标模式 UI。最快但内核黑盒程度高、深度定制受限。**建议：内容与验证期用方案 B 抢时间窗，产品化期迁到方案 A。**

### 4.4 必须自研清单（差异化所在）

1. **微信单入口多角色语义路由**（最核心）：binding 之上加 role 维度——@角色名 / 意图分类 / 会话内切换 / 代发署名规则；角色间上下文可见性与发言权预算
2. **全局记忆作用域仲裁器**：全局/组织/项目/角色四层读写规则、晋升管线、冲突合并（fail-closed，不 fail-silent）
3. **目标模式产品化闭环**：目标 → 里程碑 → 预算 → 审批门 → 进度面板 → 失败暂停/回滚，及目标拆解进任务 DAG
4. **数据流向审计面板**（一等公民功能）：实时显示本机 agent 发出了什么、发给了谁、多少 token、多少钱；宁可少一个功能，不可有一次静默上传
5. **群聊编排策略引擎**：拉群选角色、@ 派活、群记忆、成果审核回流、打断与超时接管
6. **中文渠道合规层**：企微回调加解密、飞书事件幂等、微信登录态维护、消息去重与死信
7. **数字员工身份体系与成本治理**：角色档案格式 + agent-to-agent 权限矩阵 + per-agent 预算/轮次上限/看门狗（"100 个员工"不是财务炸弹的前提）
8. **技能市场安全审核**：**不做开放市场，走"官方审核 + 本地签名"白名单机制**（ClawHub 12%–36% 恶意率是前车之鉴）

## 5. 关键设计专题

### 5.1 本地化架构与"数据主权"红线

- **形态**：本地 Gateway 常驻进程（参考 openclaw 单例网关 / tarocub bridge）+ 桌面壳（参考 Orkas/ZCode：Main 只调度，每 workspace 一个 agent 进程，stdio + JSON 事件投影）+ 多渠道插件。
- **模型策略**：混合制——本地小模型（GLM/Qwen 开源权重）做记忆蒸馏、意图分类、judge 循环、敏感过滤；云端 API 由**用户自持 key**（成本透明、数据自决）。**永远不依赖任何单一厂商的 OAuth/订阅通道**——Anthropic 2026-04-04 一刀切断第三方 OAuth、OpenClaw 用户月账单涨 50 倍是最近的重演级先例。嵌入用 **Qwen3-Embedding-0.6B**（MTEB 多语 64.33，MRL 可裁剪，Apple Silicon 毫秒级/条）。
- **数据主权必须架构可验证，不能只是文案**。反面教材就是 ZCode：2026-09-18 被用户发现"代码库索引"功能默认开启、**静默加密打包上传整个工作区**（源码、git 全量历史、数据库口令、云凭证），且关闭界面隐私开关后后台仍在传；智谱三次回应、v3.14.0 移除上传链路、被迫 9-20 开源 + 信通院/绿盟审计确认云端 OSS 零数据 + 两轮全量补偿（付费用户 8 张重置卡 + 全体 10 天 token）才压住舆情，还被企业客户发函追责（12 项答复要求、保留诉讼权利）。**教训直接写入产品宪法：① 默认零外发，外发必须显式授权且实时可见；② 把"数据流向面板"做成一等公民功能（外发内容/目标域名/token/费用实时可见），截图直接可发小红书——它同时是安全设施和最强营销素材；③ 宁可少一个功能，不可有一次静默上传。**
- **安全**：默认闭环（gateway 仅 127.0.0.1 + 配对码）；每个 agent 独立凭证存储（Grok Bot"共享一台电脑共享 cookie"且 xAI 自认"别把 Bot 当安全边界"的反面）；技能安装审批门 + capability 声明 + 签名白名单 + 沙箱档位；按工信部"六要六不要"逐条设防（独立网段、最小权限、日志留存、高危命令黑名单、敏感目录禁访）。

### 5.2 记忆体系：五层文件式全局记忆（对标并超越大厂）

**设计原则**（证据链）：OpenClaw 以纯 markdown 被社区喜爱到催生开源复刻；Muse 把"你能看到它写的 markdown 文件"当官方卖点；Anthropic 官方 memory tool 就是"客户端文件目录 + 6 个命令"；而 dots 黑盒记忆被打 4.8/10。**把「记忆 = markdown 文件 + git + 本地索引」上升为产品原则**，配四件信任设施：记忆浏览器（逐条查看/编辑/删除）、"为什么想起这条"引用链、删除范围诚实告知（Muse 反面教材的镜像）、导入/导出（文件式天然免费获得）。

```
L0 全局画像层  USER.md + profile.json        ← 唯一跨一切可见
L1 组织层      orgs/{org}/MEMORY.md           ← 数字员工团队共享
L2 项目层      workspaces/{ws}/MEMORY.md      ← 兼容现有习惯
L3 角色层      bots/{bot}/persona.md + memory/ ← 每 bot 私有
L4 情景层      journal/YYYY-MM-DD.md          ← 追加式日记，只进不出
```

- **L0 全局画像**：结构抄 Memobase（topics → sub_entries，带 content/updated_at/confidence/origin）；恒久注入 ≤2k tokens（ChatGPT 实证上限），溢出降级为检索可及；敏感分级照抄 Claude（健康/宗教/政治默认不存需 opt-in；证件号/金融账号永不存）；冲突用 bi-temporal（新事实标记旧条目 `superseded_by`，保留 90 天再物理删除）。
- **L1 组织层**：组织内 bot 读写，curated 区（团队章程类）需 owner 审批；**全局画像不自动下放**给组织会话（个人偏好不进团队上下文）。
- **L2 项目层**："叠加默认 + 显式隔离"（Claude 模型）：项目会话 = 项目记忆 + 全局画像（可单项目关闭）；**永不读取其他项目**。
- **L3 角色层**：persona 冻结快照注入（hermes 技巧，保 prompt cache）；bot 私有记忆互不可读（Grok Bot 原则）；**晋升机制**：bot 发现疑似用户级事实 → 标记 `promotion_candidate` → 夜间蒸馏审核（去重/冲突检查/信任级确认为 agent 级只可 inform 不可 act）→ 低风险自动晋升 + 通知可回滚，涉敏进用户确认队列。
- **L4 情景日记**：晚间摘要（Mem0 四操作 ADD/UPDATE/DELETE/REJECT）→ 每周合并（bi-temporal 作废）→ 每月画像槽位更新提案 + bot 晋升候选统一裁决，产出 diff 供用户晨间审阅（"你的助理本月学到了这些"——这同时是留存运营动作）。
- **两条整合铁律**（源码级教训）：
  1. **冲突时只标注，交给人裁决**——学 ZCode Dream（`core/src/memory/dream.ts`）：当新记忆与既有规则冲突时，**禁止整合 agent 自动改写规则**，只标注 `contradicts <规则> — verify which is current` 并列入 summary 供人裁决；整合 agent 的工具锁死为只读 + 只能删 memory 目录内文件；敏感路径黑名单（.git/node_modules/配置目录）禁止落记忆。
  2. **Fail closed，不 fail silent**——学 Hermes caller_scope：多员工记忆隔离最大的坑是"空上下文的 worker 静默落到默认 profile"（张三读到李四的客户档案且永远不会被发现）；解法是未显式指名作用域的调用直接拒绝，绝不降级到默认层。
- **存储与检索**：SQLite 单文件双索引（FTS5 全文兜精确术语 + sqlite-vec 向量，千条级暴力检索亚秒）；`memory_search(layer, query)` 工具对齐 Anthropic memory tool 协议。
- **防投毒（TMA-NM 四机制，8 模型 4032 次攻击 0% ASR，act-gate 确定性检查 1.3μs 零开销）**：M1 写时按认证通道绑定来源（user/trusted_tool/agent/untrusted_external）；M2 不可塑传播（派生条目继承源中最大不可信度，转述永不提权）；M3 抗 Sybil 佐证门控（不可信来源驱动高危动作需 ≥2 独立佐证或一次性用户令牌）；M4 hash chain 防篡改判定日志。**隔离原则：不可信记忆可检索可用于闲聊，但不可授权行动。**

### 5.3 多 Agent 协同：拟人员工机器人 vs 智能体 + 拉群工程学

**行业答案（Grok Bot / Manus Cue / DeepSeek-Bot 三家殊途同归）**：

> **智能体（Agent）= 模板**：persona（人设/职责/语气）+ 技能包 + 权限 + 模型配置 + 预算上限——一份可版本化、可分享、可售卖的配置，无记忆无状态、可被实例化 N 次。
> **数字员工（Bot）= 实例**：由模板实例化，拥有独立身份（头像/名字/工号）、私有记忆（L3）、渠道绑定、独立工作目录与凭证、独立成本账。

HR 心智模型：岗位 JD = 模板；李小 = 员工；发送消息 = 会话；工单 = 任务（状态由宿主代码判定，非模型自评）。三条设计原则：**① 记忆挂在实例上不挂在模板上**（员工积累的经验不该污染模板）；**② "100 个数字员工" = 「1 个模板 × N 组参数」**——销售模板 × 100 个客户 = 100 个各自记住不同客户的专员，这在云端是成本灾难（Cue 每 agent 一台云电脑，成本随数量线性增长），在本地几乎零成本，**建议把这张对比做成所有内容的封面图**；**③ 前台只暴露"员工"，"智能体"退到后台成为能力包**——用户面对人名和群聊，配置面板里才是模板和参数。

**拉群协作的运行时设计**——Orkas `group_chat/`（19,206 行生产级开源实现）的四个工程决策 + 三调度动词，全部可直接抄：

- **三调度动词**：`hand_off_to`（用户看到被委派 agent 的回复，回合结束）/ `dispatch_to`（用户看到回复，Commander 必须继续说出下一步具体动作）/ `run_worker`（用户看不到过程，只有结果回到 Commander）。配套强制规则：**Commander 必须先说出具体的下一步动作才允许 dispatch_to；如果剩下的事只是复述 agent 的回复，规则强制走 hand_off_to**——这一条阻止了多 Agent 产品最常见的失败模式"每个 agent 抢着说话、最后把大家的话复述一遍"。
- **决策一·可见性投影**：群聊是共享的，但注入每个 agent 模型的历史是按可见性规则裁剪后的**各自投影**（`group-main-v8:{cid}` vs `group-main-v8:{cid}:actor:{actorId}`）——既省 token 又防上下文互相污染。
- **决策二·任务板宿主判定**：**模型没有写板权限**；`done` 只记录"这一轮正常结束"的执行事实、`stopped` 记录宿主侧终止，**都不是质量自评**——LLM 自报"我完成了"会撒谎，完成状态必须由确定性宿主代码判定。
- **决策三·预算四件套**：per-actor 每轮 500 次工具调用上限 + 周期检查点 + 重复动作保护（防死循环）+ 空闲看门狗——**这是"100 个数字员工不会一夜烧掉你一万块"的工程答案，四件缺一不可。**
- **决策四·默认静默**：worker 干活的过程用户默认看不到，只有结果浮出水面——100 个员工往群里刷屏产品就没法用了；对应 Duet 的哲学"只在有事时找你"。
- 群聊 turn 协议抄 ds-bot：逐个发言、@转交、无话可说回 `[PASS]`、每成员每群一个隐藏会话（群永不读成员私聊）、admin 默认应答 + 按需点将。
- 派活引擎抄 dsh-agent-teams：任务 DAG（blockedBy 无环）+ 空闲成员自动领取 + 失败安全接管 + **plan-before-execution（先出排班草案，用户 Approve 才跑）**。
- 消息拆分抄 Orkas dispatch_planner：一次结构化模型调用把用户消息拆成任务板行（assignee/part/依赖），**"模型提议、宿主校验、模型永远不直接写板"**。
- **注意 Hermes 的教训**：它的拟人化群聊与 Kanban 真调度层（TASK/RUN_ID/CLAIM_LOCK/GOAL_MODE 环境变量 + 看板围栏）是两套东西，且其隔离是"协作式作用域而非强制隔离"（源码自承）。正确做法是 **Orkas 的可见性投影做成本与隔离治理 + Hermes 的 Kanban 做调度，焊接在同一个壳里**，而不是只抄其中一个。

**产品叙事**：这本身就是内容。"一个人 + 50 个数字员工"已有直接对标：技术博主孟健用 16 个 Agent 三层架构运营 13 个自媒体平台，月成本 $190 替代数万元/月运营团队——你的产品把这个过程产品化，就是"卖铲子给挖金的人"。

### 5.4 渠道接入策略（微信单入口约束的正解）

**微信官方 ClawBot 现状（2026-10）**：个人免资质、`我→设置→插件` 扫码绑定，**纯消息管道**（腾讯不留存、但内容安全审核 + 记录日志）；仅单聊、**iLink 协议不推送群消息事件——群聊在微信里连做的可能性都没有**；类客服 24h 窗口；**一个微信号 = 一个名额，重绑顶替、解绑困难**（iLink 服务端绑定，有 ret=0 假成功 bug 且"故障跟随账号"）；截至 10 月无多 bot/群聊扩容信号。机器人是独立 iLink Bot 身份（被塞进聊天列表的新联系人，不是用户自己的微信号）。

**渠道定位一句话：微信 = 遥控器，办公室在别处。** 微信承载"你 ⇄ 总管"单聊（下发指令、收结果、收晨报）；多员工群协作在本地控制台与飞书/企微里做——这个分工符合真实心智：老板在微信里遥控，员工们在办公室里干活。

**渠道矩阵（合规风险评级）**：

| 渠道 | 角色 | 风险 | 关键约束 |
|---|---|---|---|
| 微信 ClawBot 官方插件 | C 端傻瓜式一级遥控入口（扫码即用） | 低-中 | 单名额、单聊、24h 窗口、敏感词过滤；绑定的是用户主微信号需明确告知 |

| 企微·客户联系（活码/好友） | 长期陪伴型数字员工（销售/顾问人设） | 低-中 | 长期双向不受 48h 限制，但加好友有风控频控、主动群发每日 1 条 |

| 钉钉 | B 端补充 | 低 | Stream 模式本地长连接；免费额度 5000 条/月 |
| 个人微信 Hook/iPad 协议 | — | **高危，禁用** | 封号极高危 + 连带支付 + 已有项目被法务下架 + SAEP 后生态围墙已成 |

**产品形态结论**：单入口内多角色（ClawBot 唯一可行解：一个微信名额 → 前台一个总管角色 → 语义路由/导航词切换到后台多个数字员工）+ 群协作主场放本地控制台与飞书 + 需要独立身份场景导企微微信客服（一号一员工，5000 账号容量）。SCRM 行业（微伴/尘锋/探马）从未在单个个人微信里塞多个 bot，而是把"多机器人"映射为"多个企微号/客服账号 + 平台层统一编排"——这是被十万级企业验证过的答案。

## 6. 产品定义建议（OneFleet）

**一句话定位**：跑在自己电脑上的"数字员工团队"操作系统——一个人拥有一家公司，微信扫码即用，数据永不出户。

**差异化三支点**（每一点都踩在大厂的结构性软肋上，且可验证）：
1. **本地优先 vs 云端重资产**：零 VM 成本 → 定价空间碾压；隐私从承诺变架构——LightVela 官方文档亲自证明大厂不做本地；**数据流向面板让"数据不出户"变成用户可亲眼验证的事实而非文案**（ZCode 事件后，市场对"本地工具偷传数据"极度敏感，可验证本身就是差异化）。
2. **数字员工组织 vs 单体 agent**：模板化智能体 + 可拉群协作 + 组织记忆层——对标 Grok Bot/Cue 已验证的方向，但"1 模板 × N 参数"的本地经济学让"100 个员工"真实可行。
3. **微信原生 vs IM 边缘化**：大厂以自家 IM 为入口（WhatsApp/Slack/Telegram），国内用户的首页在微信——ClawBot 单聊遥控 + 企微客服矩阵是国内独有的一层产品能力。

**目标用户分层**：①🥇 超级个体/一人公司创业者（买"一个人 + 100 个数字员工"的完整叙事，付费来自业务 ROI，5000–50000 元/项目，也是内容素材来源）；②🥈 有数据合规压力的小企业主（外贸/法律/财税/医疗——"不敢"用云端 Agent 但确实需要自动化，1–10 万元/项目，能签对公合同）；③🥉 技术人/AI 重度用户（给 star、给传播、帮找 bug 的种子层）。**先靠第 3 类建信用，用第 1 类做内容和现金流，用第 2 类赚钱。**

**MVP 范围（0–3 月）**：
- 一条命令跑起来（`npm i -g` 或一键脚本，不允许出现"请先安装 Node 22"——对齐 Muse 零门槛标准）
- 本地 Gateway（dsh 内核或 openclaw 底座）+ 桌面壳
- 渠道：飞书（长连接，最先通）→ 企微微信客服 → 微信 ClawBot（单聊遥控 + 单入口多角色路由 v1）
- 五层记忆 v1（文件式 + SQLite 双索引 + 夜间蒸馏）——**把"全局记忆可视化浏览器"做成首发卖点**
- **数据流向面板 v1 + 成本面板**（per-agent 预算/轮次上限/看门狗）——数据主权与成本治理的一等公民证明
- 目标模式 v1（judge 循环 + 进度面板 + 预算 + 审批门）
- 数字员工：Chief 总管 + 5 个预置模板（总管/文案/数据/客服/运营）+ Markdown 定义 agent（YAML frontmatter，零代码）+ 群协作 v1（@派活 + 成果回流）
- 安全底座：本地闭环 + 技能审批门 + 签名白名单

**暂不做**：跨 App 代办（SAEP 围墙 + 逆向协议风险，聚焦本地文件/代码/知识库）、多用户 SaaS（备案链长且是大厂战场）、移动原生 App（Web 响应式足够）、agent 钱包/支付（合规未明）、硬件（利润被苹果赚走）、开放技能市场（恶意率前车之鉴，走审核+签名白名单）。

### 7.1 变现模式矩阵（按优先级）

### 7.2 内容与个人 IP 打法

**结构性事实先认清**：国内视频平台几乎没有广告分成，博主收入高度依赖商单——**内容本质是一门 to 大 厂市场部的 to B 生意**，目标不是赚平台钱，是建立能被厂商采购的影响力。

**平台分工**（修正后排序：小红书主战场 > B 站信任背书 > 视频号私域 > 抖音）：
- **小红书（主战场，每周 2 条图文）**：搜索长尾 90 天 + 垂类商单报价约为泛生活账号 3 倍；**实价锚点：20 万粉 AI 博主图文 4.5 万/条、视频 8 万/条（蒲公英后台口径），有博主两个月 8 条合作到手 60 万+**。你的内容资产（实操+架构拆解+成本账本）恰好是高信息密度垂类。
- **B 站（信任背书，每周 1 条 8–15 分钟长视频）**：教程型涨粉效率 280‱（热点型仅 2.2‱）；源码级拆解 + 实机演示，长视频承载复杂架构讲解。
- **视频号（私域，每月 2 条）**：复刻验证过的内容直连微信生态，35+ 高客单人群，100 粉即可开流量主。
- **抖音**：投入产出比最低，仅做结果冲击型切片分发，泛流量必须私域承接。

**内容公式**：「**一个真实任务 + 本地跑 + 成本对比 + 数据流向截图**」——大厂做不了的内容，它们不能公开讲"我的数据上了云"。配合封面图：云端方案 vs 本地方案在"100 个 agent"下的成本/主权对比表。

**选题库（直接可用）**：《我在自己电脑上开了 100 个 AI 员工，一天花了 3 块 7》《云端 AI 助手 vs 本地数字员工：同样一个任务，数据去哪了？》《拆 Hermes 的四层记忆：为什么你的 AI 用三个月还是不认识你》《多 Agent 为什么总在互相复读？三个调度动词就够了》《一人公司实测：让 100 个数字员工跑了一周，这是我的账本》《智谱 ZCode 那次翻车，给所有做本地 AI 的人上了一课》《我用 Claude Duet 和本地 Agent 跑同一个任务，差距在这》《跨行业工作流演示：外贸/自媒体/咨询各跑一条》《一人公司 OPC 展业实录：我一个人 + 100 个数字员工的第一周》。

**漏斗设计**：钩子（工作流模板/部署脚本/行业 SOP 资料包）→ 企微/微信 → 分层社群（免费答疑群 + 付费星球）→ 低价课 → 训练营/咨询/私有化项目。直播三模式中优先"演示直播"（现场把一个真实工作流从 0 跑通）与"陪跑直播"（拆解观众行业）；直播切片回流短视频。

**红线**：
- AI 生成内容强制标识（GB 45438-2025，罚款 1–10 万、封号）——数字人口播/AI 画面务必声明；不做纯 AI 生成内容（平台降权）
- 李一舟是天花板也是坟墓（199 元课 25 万套/5000 万后崩盘）；"同一批人反复收割"已被界面新闻点名——**交付 SOP 和退款机制要在起号前就绪；不复述新闻、不卖焦虑，稀缺性在于"我亲手做并跑通了"**
- 微信外链规范禁止利诱分享/砍价助力——裂变只能做"内容价值驱动"
- 收款合规见 7.3 主体选择；不承诺收益、不荐股

### 7.3 一人公司的主体、时间与天花板

**主体升级路径**：先个体工商户/个人独资低成本试错 → **月流水稳定 ≥3 万升级为一人有限责任公司**（企业客户要对公合同和专票，届时必须升级）；最狠的一条红线：**股东不能证明公司财产独立于个人财产的，对公司债务承担连带责任**——账户隔离、凭证留痕、规范计税、年度审计，公私混同 = 有限责任保护失效。

**时间分配（稳定期）**：产品 40% / 内容 25% / 销售 25% / 运营财务合规 10%；测试、CI/CD、文档、剪辑、记账全部 AI 化或外包，**观点与人格必须本人**。

**天花板的真实证据**：腾讯研究院《超级个体时代》用一整章论证一人公司跨不过的四道墙——风险（有联创的公司 5 年存活率高约 45%）、注意力、**信用（客户认组织不认个人）**、场景（需要复数的人在场）。破"信用"墙的唯一方式是**把信用产品化**：开源 star、可验证 benchmark、公开客户案例、可试用 Demo——这正是"开源 → 影响力 → 被招安"的 OpenClaw 路径逻辑。OPC 应被设计成"**可持续的小**"，而非"通往大的过渡态"；真要突破必须补联创。大盘佐证：全国 OPC 社区 2026 上半年从 95 个增至 618 个（覆盖 24 省 75 城）；可核实的 OPC 收入样本集中在"月入 1–5 万的手艺人型"（徐爽、杨默、陆阿吉），"月入百万"类案例无一可核实——**中间层稀缺恰恰说明按 1–5 万/月规划现金流是现实锚点，规模化靠产品不靠接单**。

### 7.4 为什么"现在 + 本地 + 微信"是 OPC 的最优时间窗

1. 大厂刚刚完成用户教育（Muse 40 天 1000 万下载替你教育了市场），但云端订阅贵、数据顾虑真实存在，且五家中国区全部不可用
2. 国内大厂全在云端（LightVela 书面排除本地用户），没人做"本地 + 微信原生 + 数字员工组织"的缝隙；**Manus 国内团队组建中是最大的倒计时——按 6 个月窗口规划**
3. 监管豁免纯本地自用；"六要六不要"给合规产品设了竞争门槛；SAEP 围墙替你排除了"跨 App 代办"的错误方向
4. OpenClaw 复盘证明：内容资产 + ToB 服务是穿越热度周期的两条腿，且"上一波的讲解者"心智可直接迁移
5. 目标模式的技术底座（九仓库）刚刚齐备且全部 MIT/Apache 可商用；WorkBuddy 1% 变现窗口刚刚打开——开源窗口与平台红利期叠加
